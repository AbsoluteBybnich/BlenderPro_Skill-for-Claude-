# 3Dpro - установка и проверка

## Установка в Claude Code
Самый простой способ - клонировать репозиторий сразу в папку скиллов (имя папки должно быть `3Dpro`, от него зависит команда):
```bash
git clone https://github.com/AbsoluteBybnich/BlenderPro_Skill-for-Claude-.git ~/.claude/skills/3Dpro
```
Либо вручную:
```bash
# личный скилл (доступен во всех проектах)
mkdir -p ~/.claude/skills && cp -r 3Dpro ~/.claude/skills/3Dpro
# или только для одного проекта
mkdir -p <проект>/.claude/skills && cp -r 3Dpro <проект>/.claude/skills/3Dpro
```
Запуск: `/3Dpro <задача>` - или просто опишите задачу про Blender/3D, скилл подключится по описанию.
**Регистр важен:** команда называется ровно `/3Dpro` (так задано в `name:` в `SKILL.md`; `/3dpro` не сработает).
Если нужен вариант для Claude.ai (там имя скилла должно быть строчным kebab-case): переименуйте папку в `3dpro` и в `SKILL.md` поставьте `name: 3dpro`.

## Требования для скриптов
- Blender 4.2+ (проверено на 5.2.3 LTS) **или** `pip install bpy` (колесо должно подходить к вашей версии Python: Blender 5.x - Python 3.13, 4.x - Python 3.11).
- Скрипты запускаются так: `scripts/run_headless.sh <script.py> [файл.blend] -- <аргументы>` (ищет `$BLENDER`, потом `blender` в PATH, потом модуль `bpy`).

## Проверка на вашей машине (сделайте один раз и после каждого обновления Blender)
```bash
scripts/run_headless.sh selftest.py
```
Должно закончиться строкой `RESULT: ALL PASS` (10 тестов, около 10 секунд). Упавший тест показывает, какое API изменилось в вашей версии.

## Что внутри
- `SKILL.md` - вход: как действует скилл, маршрутизация по задачам, правила, карта версий Blender.
- `references/00..10` - справочники по темам (хард-сюрфейс, анатомия/скульптинг, ретопо/UV/запекание, Unreal, окружение, риггинг/анимация, bpy, ComfyUI/FLUX, свет/рендер, пайплайны, источники).
- `scripts/` - проверенные скрипты; `assets/addon_template/` - шаблон аддона.
